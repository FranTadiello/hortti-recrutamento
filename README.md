# Hortti Recrutamento

Projeto fullstack desenvolvido para gerenciamento de produtos.

## Tecnologias:
- Frontend: TypeScript
- Backend: NestJS + TypeORM
- Banco de dados: PostgreSQL
- Autenticação: JWT
- Upload de imagens: Multer
- Docker / Docker Compose

## Como executar:

Pré-requisitos:
- Node.js
- PostgreSQL
- npm ou yarn

### Backend:
1. Acesse a pasta backend
2. Crie o arquivo .env com as variáveis de ambiente
3. Execute:
   npm install
   npm run start:dev
4. Backend disponível em http://localhost:3001

### Frontend:
1. Acesse a pasta frontend
2. Execute:
   npm install
   npm run dev
3. Frontend disponível em http://localhost:3000
